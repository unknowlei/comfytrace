# Original example fixtures

Run `npm run examples` to regenerate all files deterministically.

- `platform-workflow.json`: UI 0.4 workflow with nine nodes and twelve links.
- `platform-revision.json`: revised LoRA strength, prompt and sampler settings;
  includes an unrelated canvas move to demonstrate noise-free comparison.
- `broken-workflow.json`: deleted LoRA node with dangling links and a muted sampler.
- `api-prompt.json`: API-format prompt with seven nodes.
- `object-info.json`: minimal synthetic node availability snapshot, not a real environment dump.
- `workflow-metadata.png`: a generated 2x2 color swatch with a compressed iTXt workflow.

Model names are fictional placeholders. These examples demonstrate inspection,
not generated output, model quality, or a verified ComfyUI runtime environment.
