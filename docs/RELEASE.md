# ComfyTrace 1.0.0

An offline ComfyUI workflow inspection desk, with a Chinese interface and
English/Chinese project documentation.

## Use it

- [Open the live demo](https://unknowlei.github.io/comfytrace/)
- Download `ComfyTrace-portable-v1.0.0.zip`, extract it, and open `ComfyTrace.html`.
- No GPU, Node.js, ComfyUI server, account or API key is required for the portable app.

## Included

JSON/API/PNG imports, graph inspection, structural diagnostics, dependency
inventory, optional object_info snapshots, semantic revision comparisons,
Markdown reports, JSON manifests and a developer CLI in the source repository.

135 unit/regression/CLI tests and 14 file:// browser tests passed locally.
See the repository's validation record and GitHub Actions for exact checks.

Files stay in the browser. Reports may contain prompts and paths; review before
sharing. Static checks do not promise successful ComfyUI execution. Model names
in the bundled examples are fictional placeholders.
