ComfyTrace - 离线 ComfyUI 工作流诊断台

1. 双击 ComfyTrace.html，用新版 Chrome、Edge 或 Firefox 打开。
2. 初始示例可直接探索。导入 JSON 或含 ComfyUI 元数据的 PNG 开始检查。
3. 点击节点看参数，查看诊断与模型/节点依赖；导入另一个版本进行对比。
4. 如需核对节点安装状态，导入你的 ComfyUI /object_info JSON 快照。
5. 导出 Markdown 诊断报告或 JSON 依赖清单。

应用离线运行，无需安装 Node.js、Python、ComfyUI 或显卡环境。
关闭页面后导入状态会清空。应用不上传文件，不保存浏览记录。
导出的报告可能含提示词、模型名和路径，分享前请检查。

静态检查不能保证生成成功；子图内部和自定义节点运行时行为不在覆盖范围内。
版本对比基于节点 ID，忽略位置、尺寸等画布变化。
示例模型名为虚构占位符，示例 PNG 为程序生成的 2x2 色块元数据样本。
