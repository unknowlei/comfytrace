# Changelog

## 1.0.0 - 2026-10-02

Initial public release.

- Offline React inspection desk, readable graph navigation and paginated evidence.
- ComfyUI UI 0.4 / 1.0 and API prompt normalization.
- PNG tEXt, zTXt, iTXt and comf metadata with CRC and decompression budgets.
- Iterative graph diagnostics, dependency inventory and environment snapshots.
- Node-ID semantic comparison including conservative configuration properties.
- Markdown/JSON exports and read-only CLI with explicit exit statuses.
- Single-file portable HTML, original examples and bilingual project documentation.
- Unit, independent regression, CLI and file:// browser tests.

Pre-release review corrected subgraph endpoint handling, UI-only node inventory,
property/type diff omissions, informational PNG warnings, cross-format equality
messaging, and keyboard access to scrollable evidence.
